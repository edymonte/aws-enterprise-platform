# Interview prep pack — AWS / multi-cloud DevOps

| File | Use it for |
|---|---|
| [01-pitch.md](01-pitch.md) | 30-second and 2-minute story of this platform (and the multi-cloud angle) |
| [02-technical-answers.md](02-technical-answers.md) | ~30 AWS questions with model answers, tagged with SAA-C03 domains |
| [03-consultant-scenarios.md](03-consultant-scenarios.md) | Consulting questions and STAR templates |
| [04-interview-english.md](04-interview-english.md) | Phrase bank, false friends, pronunciation |

**How to answer:** clarify → one-sentence answer → why (trade-off) → real example → risk/alternative. Say it **out loud**, ≤ 2 minutes.

If the role is Azure-focused, use this pack for the "have you worked with AWS?" moment: answer with the **mapping** (`docs/AZURE-AWS-MAPPING.md`) — "Yes, I built the same platform on both clouds; the main differences were…".
